# UI revamp — Salon de l'objet aesthetic (2026-05-21)

**Direction:** Painterly editorial B2B SaaS — *Apartamento* / *Cereal* / 1970s French gallery brochure. Not generic dashboard SaaS.

**Changes:**
- New palette (ink, terracotta, ochre, butter polaroids) and typography stack: DM Serif Display, EB Garamond, Geist Sans, JetBrains Mono, Caveat.
- Painterly radial blob backgrounds, arched image frames, polaroid result cards with fixed rotations, conic score gauges.
- Editorial copy: "The salon", "Back of house", "Tasting notes", Roman numeral admin tabs.
- Mobile-first responsive layout: stacked on small screens, asymmetric 1.15/1fr split on large.
- Stylized SVG furniture silhouettes on result cards until product photography exists.

**Fonts:** Google Fonts + `@fontsource/geist-sans`.
